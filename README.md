# React JS Interview Questions and Answers for Developers

An interactive, single page landing site for developers preparing for react js interviews. Flip flashcards, filter 18 questions by topic, check your readiness with a live meter, and jump to guides, courses and a free demo class.

No build step. No dependencies. One HTML file.

## What is inside

- A flashcard deck that deals 8 random questions, lets you flip each card and mark it as nailed or needs practice, then gives you a score
- A topic explorer with filter chips, keyword search and expandable answers
- A readiness checklist with a progress meter and a small confetti moment at 100 percent
- Resource cards linking to four articles, three courses and one bootcamp
- Sticky header, mobile menu, modern footer, keyboard focus styles and reduced motion support

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Publish it with GitHub Pages

1. Push the files to a GitHub repository.
2. Open Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and the `/ (root)` folder, then save.
4. Your site goes live at `https://your-username.github.io/react-js-interview-questions-landing-page/` in a minute or two.

## Customise

- Questions and answers live in the `Q` array near the bottom of `index.html`
- Readiness checklist items live in the `ITEMS` array
- Colours and fonts are CSS variables at the top of the `<style>` block
- All external links open in a new tab with `rel="noopener"`

## Links used on the page
